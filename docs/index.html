RankIdleとは？

FANZA Web Service APIのランキングを定期観測し、順位変動・ジャンル・価格帯・新作傾向を可視化する非公式サイトです。

販売数・売上・閲覧数を示すものではありません。

API RANKING — FANZA Web Service APIの sort=rank を定期観測。FANZA公式サイトの1時間 / 24時間ランキングとは別の観測値です。

RISING TOP5

前回観測から順位が上昇した作品を、上昇幅順に最大5件表示。NEW / REENTRYは単純比較できないため含みません。

UP / DOWN / STAY

UP 順位上昇　DOWN 順位下降　STAY 変化なし。いずれも前回観測との比較です。

NEW

RankIdleのAPI観測上、今回初めて観測された作品。発売直後という意味ではありません。

REENTRY

一度観測外になった後、再びランキング内で観測された作品です。

NEW RELEASE

release_dateをもとにした発売7日以内の作品。ランキングstatusのNEWとは別です。

MOMENTUM

直近複数回の観測で継続して順位が上昇している場合に表示。売上増加を意味しません。

TOP10観測率

週次観測期間中、対象ジャンル作品のうちTOP10で観測された作品数の比率。販売率・購入率ではありません。

WEEKLY GENRE WATCH

保存したAPIランキングsnapshotから、ジャンル、新作比率、TOP10観測数、ジャンル別価格中央値などを集計します。

PRICE

DMM/FANZA APIから取得した商品価格。価格中央値は観測作品の価格中央値です。

NOTICE

RankIdleが扱うのはランキング観測データです。販売数・売上・閲覧数・購入率は取得、表示していません。「売れている」「人気が高い」「このジャンルなら売れる」ことを示すものではありません。
